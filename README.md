\# Guía de Git y GitHub



Una guía web interactiva, práctica y en español para aprender a utilizar \*\*Git y GitHub\*\*, desde los conceptos fundamentales hasta los flujos de trabajo más habituales en proyectos de software.



El objetivo es facilitar el aprendizaje de Git mediante explicaciones claras, comandos listos para copiar y ejemplos de situaciones reales.



\## 🚀 Características



\- \*\*Guía de comandos:\*\* comandos esenciales de Git con explicaciones.

\- \*\*Flujos de trabajo interactivos:\*\* instrucciones paso a paso para diferentes escenarios.

\- \*\*CMD y PowerShell:\*\* ejemplos adaptados a terminales de Windows.

\- \*\*Buscador integrado:\*\* encuentra rápidamente comandos y conceptos.

\- \*\*Filtros por categoría:\*\* configuración, ramas, sincronización, flujo de trabajo y más.

\- \*\*Copiar comandos:\*\* copia instrucciones directamente al portapapeles.

\- \*\*Diseño responsivo:\*\* compatible con computadoras, tabletas y dispositivos móviles.

\- \*\*Modo claro y oscuro:\*\* adaptación automática a las preferencias del sistema.

\- \*\*Preguntas frecuentes:\*\* respuestas a dudas comunes sobre Git y GitHub.



\## 📚 Contenido



La guía incluye los siguientes temas:



1\. Introducción a Git y GitHub.

2\. Configuración inicial de Git.

3\. Creación y clonación de repositorios.

4\. Estados de los archivos y commits.

5\. Creación y administración de ramas.

6\. Sincronización mediante `fetch`, `pull` y `push`.

7\. Fusión de ramas con `merge` y `rebase`.

8\. Recuperación y reversión de cambios.

9\. Flujos de trabajo y colaboración.

10\. Resolución de errores frecuentes.

11\. Herramientas de GitHub y GitHub CLI.



\## 🔄 Flujos de trabajo



Una de las principales funcionalidades de la guía es su apartado de escenarios prácticos, diseñado para responder a la pregunta: \*\*¿Qué debo hacer según mi situación actual?\*\*



\### Escenario A: Mi primer proyecto



Aprende a crear un proyecto desde cero, incluso si todavía no tienes una carpeta ni archivos.



Incluye la creación de directorios, inicialización de Git, primer commit y publicación en GitHub.



\### Escenario B: Ya tengo un proyecto clonado



Aprende el flujo cotidiano para actualizar archivos, registrar cambios y sincronizar tu proyecto con GitHub.



\### Escenario C: Trabajo en equipo



Aprende a trabajar con ramas independientes, desarrollar funcionalidades, publicar cambios y colaborar mediante Pull Requests.



\### Escenario D: Estoy en mi PC habitual



Aprende a continuar trabajando con un repositorio que ya tienes configurado en tu computadora.



\### Escenario E: Estoy en otra PC



Aprende a recuperar tu proyecto desde GitHub en una computadora diferente, tanto si es la primera vez que lo descargas como si ya existe una copia local.



También se explica cómo evitar perder trabajo al cambiar entre computadoras y por qué es importante publicar los commits antes de cambiar de equipo.

\## 💻 Cómo utilizar la guía



1\. Descarga el archivo HTML del proyecto.

2\. Ábrelo en un navegador moderno.

3\. Selecciona la categoría que deseas consultar.

4\. Explora los comandos o elige un escenario práctico.

5\. Utiliza los botones para copiar los comandos que necesites.



La interfaz puede funcionar localmente sin un servidor. Para utilizar los comandos de sincronización con GitHub, necesitarás Git instalado y acceso al repositorio remoto.



\## 🌐 Publicación con GitHub Pages



La guía también puede alojarse gratuitamente utilizando GitHub Pages.



1\. Sube los archivos a un repositorio de GitHub.

2\. Nombra el archivo principal como `index.html`.

3\. Abre \*\*Settings → Pages\*\* dentro del repositorio.

4\. Selecciona \*\*Deploy from a branch\*\*.

5\. Elige la rama `main` y la carpeta `/ (root)`.

6\. Guarda la configuración y accede a la URL publicada.



\## 🎯 Objetivo del proyecto



Ofrecer una herramienta educativa que permita a estudiantes, desarrolladores principiantes y cualquier persona interesada en el desarrollo de software comprender Git y GitHub de forma progresiva.



La guía busca enseñar no solamente \*\*qué comandos ejecutar\*\*, sino también \*\*cuándo utilizarlos, por qué son necesarios y qué sucede después de ejecutarlos\*\*.
